`결과 메일 보내기` 단추로 roeh98@gmail.com 에 메일이 자동 발송됩니다.
(노트북에서 하는 것을 권장합니다. 약 15분)

준비물: 구글 계정(roeh98@gmail.com 권장), GitHub 계정(무료)

## 1단계. 구글 시트 만들기
1. https://sheets.google.com 접속 → **빈 스프레드시트** 만들기
2. 이름을 `달콤이 영어단어`로 변경 (탭은 처음 실행 때 `log` 탭이 자동으로 만들어집니다)

## 2단계. 서버 코드 붙여넣기
1. 시트 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 기본으로 있는 코드를 모두 지우고, 함께 드린 **Code.gs** 내용을 전부 붙여넣기
3. 맨 위 `CONFIG` 에서 두 가지를 수정
   - `KEY`: `CHANGE-ME-SECRET` → 나만 아는 긴 문자열 (예: `dalkomi-7391-pink`)
   - `UNITS`: 단원별 단어 수. 지금은 DAY01~30이 모두 25개씩입니다
   - 메일 주소(`MAIL`)와 금액(`CAP`, `EXAM` 등)도 여기서 바꿀 수 있습니다
4. 저장(💾)

## 3단계. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → 유형 **웹 앱**
3. 설정
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 권한 승인 창이 뜨면 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → **허용**
   (메일 발송과 시트 읽기·쓰기 권한입니다. 내 스크립트라서 나오는 경고입니다)
5. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사

> 코드를 수정한 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포** 를 해야 반영됩니다.

## 4단계. 서버 작동 확인
브라우저 주소창에 아래처럼 입력해서 열어 봅니다 (URL과 KEY는 내 것으로).

    웹앱URL?key=내KEY

`{"ok":true,"state":{"pts":0,...` 같은 글이 보이면 성공입니다.
`{"ok":false,"err":"auth"}` 가 나오면 KEY가 다른 것입니다.

## 5단계. 앱에 서버 주소 넣기
1. 함께 드린 **dalkomi-deploy 폴더(또는 dalkomi-deploy.zip 을 푼 것)** 안의 `index.html` 을 메모장으로 열기
2. 맨 위쪽의 두 줄을 수정

       const API='복사한 웹 앱 URL';
       const KEY='Code.gs 에 넣은 KEY';

3. 저장

## 6단계. 인터넷에 올리기 (GitHub Pages, 무료)
1. https://github.com 로그인 → 오른쪽 위 **+ → New repository**
   - 이름 `dalkomi-english`, **Public**, **Create repository**
2. **uploading an existing file** → dalkomi-deploy 폴더 **안의 내용 전부**(index.html, sw.js, manifest.json, icon 두 개, audio 폴더)를 끌어다 놓고 **Commit changes**
   - 총 35개 파일(약 9MB)이라 한 번에 올라갑니다. audio 폴더째 끌어다 놓으면 됩니다.
3. 저장소 **Settings → Pages** → Branch를 `main` / `(root)` 로 선택 → **Save**
4. 1~2분 뒤 `https://내아이디.github.io/dalkomi-english/` 주소가 생깁니다
5. 이 주소를 폰, 태블릿, 노트북에서 **인터넷이 켜진 상태로 한 번** 열기 (이때 발음 파일이 기기에 저장되어 이후엔 오프라인에서도 소리가 납니다)
   - 안드로이드: 크롬/삼성 인터넷 메뉴 → **홈 화면에 추가** (또는 앱 설치)
   - 아이패드: 사파리 공유 → **홈 화면에 추가**

> 앱 파일을 나중에 고쳐서 다시 올릴 때는 `sw.js` 맨 위의 `dalkomi-v1` 을 `dalkomi-v2` 처럼 올려야 기기들이 새 버전을 받습니다.
> 주의: GitHub Pages 주소는 누구나 열 수 있습니다. 앱 파일에 KEY가 들어 있으므로
> KEY 외에 개인정보는 넣지 마세요. 용돈 기록은 내 구글 시트에만 저장됩니다.

## 확인해 보기
- 홈 화면 용돈 칸 아래에 `☁️ 동기화됨` 이 보이면 연결된 것입니다.
- 한 기기에서 학습한 내용이 다른 기기에서 `1분 이내` 또는 앱을 다시 열 때 반영됩니다.
- 인터넷이 끊기면 `📴 오프라인` 으로 표시되고, 연결되면 자동으로 올라갑니다.

## 시트(log 탭) 보는 법
| 열 | 뜻 |
|---|---|
| date | 날짜 |
| cycle | 용돈 지급일 묶음 (예: 2026-11-21 = 11월 21일에 지급할 용돈) |
| dev | 기기 표식 |
| type | start(오늘 단원 시작) / word(단어 학습 완료) / exam(시험) / report(결과 메일) |
| unit | 단원 번호 |
| score, grade | 시험 점수, 등급 |
| amount | 이 줄로 적립된 금액(원) |
| note | 시험에서 틀린 단어 |

- **매달 21일 지급액** = 그 달 cycle 값이 같은 줄의 `amount` 합계
  (시트 아무 칸에 `=SUMIF(D:D,"2026-11-21",K:K)` 입력)
- 잘못 적립된 금액은 `amount` 칸을 직접 고치면 앱의 용돈에도 반영됩니다.
- 규칙(하루 한도·1단원·복습 제외)은 서버(Code.gs)가 판정하므로, 기기 날짜를 바꿔도 한도를 넘길 수 없습니다.
  (오프라인 기록은 3일 이내 날짜만 인정됩니다.)

## 문제가 생기면
| 증상 | 확인 |
|---|---|
| `⚠️ 비밀키 오류` | index.html 의 KEY 와 Code.gs 의 KEY 가 같은지 |
| 계속 `📴 오프라인` | 웹 앱 URL이 맞는지, 배포의 액세스 권한이 "모든 사용자"인지 |
| 메일이 안 옴 | 스팸함 확인, 3단계의 권한 승인을 했는지 (메일은 시트 주인 계정에서 발송) |
| 코드를 고쳤는데 그대로 | 배포를 **새 버전**으로 다시 해야 합니다 |
